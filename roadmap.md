## 1. MARKET CONTEXT: RISING DEMANDS (Evidence)

The labor market is splitting into two tracks—**democratised** (easier for non-experts) and **professionalised** (more expert-focused). The latter is winning.

**Key Evidence:**
- **PwC AI Jobs Barometer (2026):** Professionalised roles are growing **twice as quickly** as democratised roles. Skills in AI-exposed jobs are changing **more than twice as fast** as low-exposure roles — a **75% increase in the gap year-over-year**.
- **Seniorised Junior Roles:** Entry-level positions now require traditionally senior competencies (strategic thinking, judgment, evaluation design). These roles have grown **35% since 2019**.
- **OpenAI AI Jobs Transition Framework:** **~18%** of jobs face high automation risk; **~24%** will reorganise (not disappear); **~12%** will grow with AI. The framework explicitly calls for workers to **craft personal portfolio pathways** rather than wait for static job predictions.
- **Capability Overhang:** AI could do far more than it is actually deployed to do. The gap is **skills + proof**, not technology availability.

**Implication:** Workers don't just need "new skills." They need **proof artifacts**, **portfolio identity**, and **immediate income pathways** while they transition.

## 7. TECH STACK (Final Specification)

| Layer | Stack | Purpose |
|---|---|---|
| **Frontend** | Next.js / React (migrate from GitHub Pages) or enhanced static site with embedded dynamic forms | CV upload UI, job link/parser display, cohort dashboard, artifact roadmap visualization |
| **CV Parsing** | PyMuPDF / pdfplumber + python-docx | Extract skills, experience, artifacts from uploads |
| **Job Scraping / Parsing** | BeautifulSoup4 + requests (URL mode) + manual parser (text mode) | Extract requirements from any job posting |
| **LLM Intelligence** | OpenAI API (GPT-4o) or Claude API | Gap analysis, Idealized Profile generation, Artifact Roadmap, Offer Strategy matching, certification recommendations |
| **Backend / API** | Python + FastAPI | Orchestrate parsing → LLM → database; handle cohort logic |
| **Database** | PostgreSQL (Supabase / Neon) | User profiles, CV data (encrypted), credit balances, cohort memberships, artifact progress |
| **File / Artifact Storage** | AWS S3 / Cloudinary | Generated .docx outputs, portfolio PDFs, benchmark templates, guide PDFs |
| **Auth** | Clerk / Firebase Auth | User accounts, cohort access, payment identity |
| **Payments** | Stripe (international + local integration) | Credits, cohort fees, toolkit sales, marketplace commissions |
| **Analytics / Cohort Tracking** | PostgreSQL queries + lightweight React dashboards | Progress tracking, gap closure metrics, instructor analytics |
| **Deployment** | Docker + Vercel/Render + GitHub Actions | Maintain GitHub ecosystem continuity; CI/CD for updates |

**Lightweight Launch Option:** Keep GitHub Pages for marketing/landing. Use embedded form + Zapier → Python backend (Render) → Email/link delivery. Upgrade to full stack at Cohort revenue milestone (RM199 packages).
